# 全科核心素养提分系统 V2.0

> 基于 AI 驱动的全自动理科题库采集、打标与管理引擎

---

## 项目简介

本系统是一套面向中国中小学理科（数/物/化/生）的智能题库自动化建设系统。
通过两阶段的 AI 流水线，将互联网上的真题原卷，自动清洗、验证、打标、入库，
生成结构化、多语言（zh + en）、可检索的高质量题库。

---

## 核心架构（两阶段流水线）

  阶段一：skill-genbasicinfo（先建知识地图）
    输入：年级 + 学科
    输出：知识点组合 JSON（知识点 + 有效组合）

  阶段二：skill-gendb（再往地图里找题）
    输入：题目来源链接 / 本地 Word 文件
    输出：SQLite 题库记录（双语 + 难度 + 解法）

  数据库路径：data/question_bank.db

---

## 数据规范

  语言：入库同步输出 zh（简体）+ en（英文），未来可扩展 zh-TW / ja
  公式：全部 $$LaTeX$$ 包裹，KaTeX 渲染
  图片：图文分离，只存相对路径，Pandoc 防错位提取
  难度：L1~L9，双引擎算法（结构广度分 + 认知深度分）
  题型：选择题 | 填空题 | 解答题
