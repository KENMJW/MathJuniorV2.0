# 任务：全科门户首页 (AllSubjectsPortal) 手机与平板端 UI/UE 响应式重构

## 1. 目标

重构全科门户入口首页（`src/AllSubjectsPortal.tsx`）的视口响应式与人机交互设计，彻底根除手机端（Phone, <768px）排版混乱、元素重叠、严重横向滚动条（>1020px 溢出）以及平板端（Pad, 768px~1024px）横竖屏布局失衡问题。
打造兼具 Apple 极简美学与高触控工效的 3 级响应式矩阵：
1. **手机端 (Phone <768px)**：单列轻量流式卡片，48px Slim Header 品牌收敛，2x2 紧凑大数字指标网格，SVG 函数曲线转为优雅半透明背景水印，全宽 48px 大圆角 CTA 按钮，全屏绝对 0 水平滚动条；
2. **平板端 (Pad 768px~1024px)**：iPad Portrait (768px~834px) 与 Landscape (1024px~1180px) 双断点流式适配，Hero 卡片图文等比优雅收放，学科卡片 3 列平铺，指标条居中平整，零裁切零贴边；
3. **桌面端 (Desktop >1024px)**：100% 保持已有 1140px Keynote 宽屏大剧场模式与高阶微光动效，零回归。

## 2. 上下文与现状分析

- **涉及核心文件**：
  - `src/AllSubjectsPortal.tsx`（首页全部结构、组件与内联样式）
  - 可配合 `src/index.css`（如需补充公共响应式辅助 CSS 类或媒体查询变量）
- **现状缺陷定位**：
  1. **顶栏拥挤压迫**：Header 采用固定 `display: flex` 横排 5 个控制胶囊（Logo、大标题、副标题长文案、通知铃铛、语言切换、学员状态长徽章）。在手机屏幕（375px~430px）下，文字与按钮发生严重折行堆叠，遮挡内容；
  2. **Hero 大卡尺寸爆炸**：初中数学旗舰卡内，左侧内容声明 `maxWidth: 660px`，右侧自研 SVG 函数插画容器声明固定 `width: 360px; height: 220px; flexShrink: 0;`，两者横排相加最小宽度达 `1020px`，在手机（390px）和平板竖屏（768px）下强制撑开视口，产生巨大的横向滑动与左右晃动；
  3. **四大指标横排挤死**：指标条硬编码 `gridTemplateColumns: repeat(4, 1fr)` 配 `padding: 14px 18px`，在窄屏下每个单元格被压缩至 70px 左右，导致数字被截断、下方说明文字逐字竖排折叠；
  4. **学段切换标签溢出**：三学段切换器（小学、初中、高中）标签文案较长，窄屏下超出屏幕可视宽度；
  5. **学科卡片网格断点缺失**：其他学科网格采用 `repeat(auto-fill, minmax(250px, 1fr))`，在部分平板竖屏和折叠屏视口下出现单卡孤立或宽度不对称拉伸。

## 3. 具体步骤与交付块

### 块 A：手机端 (<768px) 紧凑单列流式重塑

1. **Slim 导航顶栏（48px 高度）**：
   - 保留 App 黑底 Logo 与主标题「全科核心素养」（单行收敛，字号 14px 粗体，超出 ellipsis 截断）；
   - 在手机视口下自动隐藏副标题长文案（"覆盖小学、初中、高中..."）与冗余的"学员模式"长胶囊；
   - 右侧仅保留紧凑的语言切换胶囊（文案精简为 `EN` / `中`，高度 30px）与轻量通知按钮；
   - 顶栏固定高度 48px，背景高透毛玻璃 `backdrop-filter: blur(20px)`，底部单像素精致细线。
2. **三学段分段胶囊响应式紧凑化**：
   - 窄屏下文案自适应精简：
     - 中文：`小学 (4科)` / `初中 (8科·首发)` / `高中 (8科)`；
     - 英文：`Primary (4)` / `Junior (8)` / `Senior (8)`；
   - 弹性自适应宽度，水平居中，边距留白 12px，支持手指横向滑动或弹性平分。
3. **初中数学旗舰 Hero 卡片流式重排**：
   - 容器改为纵向流式：`flex-direction: column`，内边距调整为 `20px 16px`；
   - **自研高斯函数 SVG 插画转为背景水印**：
     - 手机端不再把 360px 的 SVG 插画放在右侧或下方硬占位；
     - 将 SVG 插画容器设为绝对定位背景水印 (`position: absolute; right: -20px; bottom: -10px; width: 220px; height: 140px; opacity: 0.12; pointer-events: none; z-index: 0;`)；
     - 既保留了高斯正态分布曲线与数学发光极值点的极致科技氛围，又将 100% 黄金垂直空间留给人机交互内容。
   - **四大核心指标改为 2x2 大数字紧凑网格**：
     - `grid-template-columns: repeat(2, 1fr)`；
     - 4 个单元格整齐划分为田字格，边框精致（上左内线），大数字 20px~22px 加粗，辅助标签 11px 清晰呈现，杜绝文字竖排换行；
   - **大圆角主操作 CTA 按钮**：
     - 按钮宽度设为 `100%` 全宽填满，高度提升至 `46px~48px`；
     - 文案居中，加右箭头，触控高亮反馈灵敏，手指点击舒适自然。
4. **学科卡片单列触控优化**：
   - 初中其他 7 学科、小学 4 学科、高中 8 学科卡片在手机端采用单列或等宽双列流式；
   - 卡片高度紧凑化为 88px~96px，主标题与阶段标签左右对齐，下方描述两行溢出省略；
   - 触控反馈改为点击缩放微动（active: `scale(0.98)`）。
5. **绝对零水平溢出保障**：
   - 页面根节点与 `<main>` 容器强制设置 `overflow-x: hidden; width: 100%; max-width: 100vw; box-sizing: border-box;`；
   - 杜绝任何绝对定位子元素外溢导致页面晃动。

### 块 B：平板端 (768px~1024px) 横竖屏自适应与平铺

1. **iPad Portrait (竖屏 768px~834px)**：
   - 顶栏保留完整标题与语言切换；
   - Hero 卡片采用流式分栏或上下紧凑排布：
     - 左侧文本与 4 指标条宽度自适应填满；
     - 4 指标条平滑采用 4 列横排，字号微调至 18px，内边距设为 `10px 12px`，严禁截断与挤压；
     - SVG 插画等比缩小至 `240px`，自适应融入右侧或底部；
   - 学科网格自动适配为 **2 列平铺**，卡片内边距规整，间隙 `14px`。
2. **iPad Landscape (横屏 1024px~1180px)**：
   - 自动展开为桌面级宽屏体验：Hero 卡片左侧 60% 文字 + 右侧 40% SVG 图形优雅并置；
   - 学科网格自动平铺为 **3 列网格**；
   - 容器左右留白 `24px`，无多余空隙，无贴边裁切。

### 块 C：桌面端 (>1024px) 1140px 宽屏影院 100% 零回归

1. 桌面端宽度锁定在已有成熟标准的 `maxWidth: 1140px; margin: 0 auto;`；
2. 保持原有 Keynote 风格白色卡片、细腻圆角、悬浮 `translateY(-2px)` 微微升起微动特效；
3. 原有高斯函数曲线 SVG、四大横排指标条、学段切换高亮胶囊与语言切换逻辑 100% 保持完全一致；
4. 确保在 1440px / 1920px 桌面显示器上像素级零变动、零样式退化。

## 5. 红线 / 禁止事项

1. **源码零 emoji**：遵循铁律 11，界面图标一律使用 `<Icon name="..." />` 或内联 SVG，严禁在 JSX/TSX/CSS 中写入任何 emoji。
2. **安全防护**：严禁引入 `eval`、`innerHTML` 或 `foreignObject`。
3. **i18n 完整性**：必须保持中英文双语完整切换，手机端与平板端精简文案必须经过 `t(...)` 或条件分支妥善处理中英双语。
4. **桌面端零破坏**：桌面端（>1024px）原有已发布的排版、阴影、微光背景与交互逻辑严禁受手机端响应式改动干扰。
