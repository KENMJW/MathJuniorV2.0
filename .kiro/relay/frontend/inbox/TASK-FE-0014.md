## 核心升级内容（按契约总表10大类）

### 1. 引擎架构：从"点连线"升级为"契约驱动渲染"
现状 `SandboxRenderer.tsx` 靠"点数量→连线"(2点segment/3点三角/4点四边)盲目拓扑。升级为：**读 canvas_template 类型 + carrier 声明式图元规格(functiongraph/line/point/segment/circle + condition 条件显隐)按类型分发渲染**。参考 LM-9A-18 规格的 carrier.elements 结构。

### 2. 必须新增的关键渲染能力（契约总表标🚨为全新研发）
- 🚨 **圆图元**：`board.create('circle')` + 切线/圆周角/垂径/内切圆（第七类，现在完全无画圆能力）
- 🚨 **三视图正交投影**：离散网格渲染（第十类 LM-9B-35）
- **函数解析式渲染**：抛物线 y=ax²+bx+c、反比例 y=k/x、一次函数，按系数滑块实时重绘（二/三/四类）
- **判别式条件显隐**：Δ≥0 才显示交点 x1/x2，Δ<0 平滑隐藏（LM-9A-18）
- **双三角形拓扑分离**：全等/相似/射影两独立三角形+对应色，废除"多点连一畸形多边形"（第五类）
- **从动约束闭环**：特殊四边形 D=A+C−B 向量从动、中点四边形（第六类）
- **数轴动力学**：动点 x=x₀+vt、区间距离、夹逼高亮（第一类）
- **几何变换/轨迹**：轴对称镜像、旋转、加权折线（胡不归/阿氏圆轨迹）（第八类）

### 3. 滑块真正驱动系数（全局根治 param_t 空转）
引擎读契约里的**具名系数滑块**(param_a/b/c、slope_k、inv_k、radius_r…)，拖动实时驱动对应图元数学量重算重绘。不再是通用 param_t 硬位移。

### 4. 遥测公式引擎
按契约 `telemetry_invariants` 规格实现**安全公式求值（禁 eval，用纯函数/表达式解析器）**，读 formula+deps+condition，实时计算判别式/韦达和积/面积恒等/距离并显示，支持 condition 条件显隐(如 Delta>=0 才显示)。
