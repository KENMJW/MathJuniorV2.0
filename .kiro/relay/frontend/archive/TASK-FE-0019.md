# 任务：全模块二级菜单Pad与手机端滚动固定悬浮及三大模块交互排版重构

## 1. 目标

依据最新线上验收反馈，彻底解决初中数学工坊在手机端（Phone, <768px）与平板端（Pad, 768px~1024px）下的四个关键体验痛点：
1. **全模块二级菜单滚动固定悬浮**：电脑版本中固定的各模块二级菜单（概念精讲、思维图谱、实验探究、实战测评），在 Pad 和手机版里面一滚动即固定悬浮吸顶（`position: sticky; top: 0;`），呈现 Apple 液态玻璃微光、高斯模糊与悬浮阴影，随滑随在；
2. **模块一（概念精讲）选考点抽屉完整展示**：取消抽屉内部 38% 独立纵向嵌套滚动分割，改为顶部紧凑横滑分类胶囊（高度 <= 72px）+ 抽屉全高单列考点列表，加上底部安全区内衬（80px 避让），杜绝“选考点看不全、滚动也看不全”；
3. **沙盒模块垂直滑屏解除死锁**：将画布外层与 SVG 背景死锁的 `touch-action: none` 优化为 `touch-action: pan-y !important;`，仅对可拖拽动点与控制柄挂载 `touch-action: none`，消除空白处滑屏黑洞；
4. **模块四（实战测评）智能组卷第二层移动端响应式重排**：头部自适应两行折叠、6 个学期药丸转横向滑动条、考点复选卡片转为大触控靶心（>=44px），同时第一层与第三层网格在移动端转为 1 列流式排版。

## 2. 验收判据（AC）

1. **AC-1（全模块二级菜单固定悬浮）**：
   - 模块一 `.concept-nav-header`、模块二 `.graph-nav-header`、模块三 `.sandbox-sticky-header-container`、模块四 `.exam-subnav-sticky-header` 在手机端与平板端滚动时始终吸附在顶部（`top: 0`），具备背景模糊与悬浮投影；
   - 桌面端（>1024px）原有吸顶与排版不受任何破坏（零回归）。
2. **AC-2（模块一考点抽屉完整展示与畅快滚动）**：
   - 在 390x844 视口下展开抽屉，年级/学期/单元位于顶部单行紧凑横向滑动条，无需在上下两个小窗口之间来回嵌套滚动；
   - 考点列表（`.concept-drawer-right-col`）获取抽屉 85% 以上高度，能一滑到底查看全部考点，底部卡片完全露出来，不被底部边缘截断。
3. **AC-3（沙盒模块垂直滑屏）**：
   - 在手机视口下手指按在沙盒画布空白区域或网格上下滑动，整个页面顺畅上下滚动，无锁死现象；
   - 触控动点（如手拉手模型的 B/C 点或二次函数抛物线动点 P）时仍能精准拖曳并触发参数与图形联动。
4. **AC-4（模块四智能组卷第二层移动端排版）**：
   - 在 390x844 视口下，智能组卷中心第二层（学期覆盖与考点子集）头部自适应换行，搜索框与全选/清空按钮排列整齐，无横向溢出；
   - 6 个学期药丸为横向滑动胶囊栏；考点复选单项触控热区 >= 44px，点击整行可切换勾选。
5. **AC-5（工程与自动化测试）**：
   - `pnpm test` 全量通过（54 文件，323+ 测试全绿）；
   - `pnpm run build` 0 错误；
   - 真实 Chrome E2E 验证脚本通过并截图。
