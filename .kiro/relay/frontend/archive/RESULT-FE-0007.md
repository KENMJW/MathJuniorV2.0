# RESULT-FE-0007: 交互系统层系统性修复与浏览器 E2E 验收

## 1. 修复成果概要
- **沙盒渲染器重构 (SandboxRenderer)**：全面移除了传给 JSXGraph 的 `var(--...)` 色值变量，统一替换为合法的标准颜色（如 `#0071e3`）。增设了模板分发逻辑（`canvas_template` 路由），当模板为数轴类（`number_axis_`）时主动绘制带有刻度的数轴与连线，当模板为几何类（`geometry_`）时按点数自动连线并填充，彻底告别了“孤立一个点”的贫乏场景。
- **ID 剥离与中文名转化**：重构了 `MathJuniorHome.tsx` 等入口，对所有的沙盒模型及母题资源通过异步预取真实库（或通过跨库 Join 逻辑）翻译成真实的 `name_zh`。同步给所有卡片和侧边栏文字添加了 CSS 截断（`textOverflow: 'ellipsis'`）及 `title` 属性，防患长文本破版溢出。
- **SVG 图层阶梯点亮**：移除了硬编码的单一标签屏蔽逻辑，在 `SvgLayerReveal.tsx` 中注入了一套涵盖四阶段的状态类（`stage-1` ~ `stage-4`）。现在，只要原生图纸设计了 `.layer-stage-N` 层级结构，图形就会随着四段论 Tab 的切换，呈现精准平滑的“淡入点亮”效用。
- **四级联动与快练修复**：在 `ConceptNav.tsx` 新增了防空挡的 `useEffect`。一旦真库数据抵达，若原选中点未命中真库，会即刻自动抓取数据表中第一个合法考点以复位四级（年级/学期/领域/考点）选择器；修复了单选题抽取语句中错误的双引号 `"single_choice"`，换用标准的单引号 `'single_choice'`。
