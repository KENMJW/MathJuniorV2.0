## 1. 背景与问题定性（Kiro 已实测确认）

用户真机验证发现 **LM-9A-18「一元二次方程判别式与韦达对称代数模型」** 严重问题：名字宣称"判别式+韦达定理"，画布却只画一条连接 x1(-2,0)、x2(3,0) 两个孤立点的**水平线段**，无抛物线、无 a/b/c 参数、无判别式 Δ、无韦达等式；结论是通用兜底"刚体变异保距性成立"，对称轴标签是未渲染的英文占位。

Kiro 全库摸底确认这是**系统性问题**，非个案：
- 36 个跃迁模型中 35 个参数滑块全是空转的 `param_t`（除 DATA-0006 新建的 LM-9B-37），**无一个模型的滑块驱动真实数学量**（a/b/c/k/斜率）。
- 至少 10 个模型名字带函数语义却无函数系数滑块，几乎必然"挂羊头卖狗肉"：LM-7B-05、LM-8B-15、LM-8B-16、LM-9A-18、LM-9A-25、LM-9A-26、LM-9A-27、LM-9A-28、LM-9B-34、LM-9B-36。
- 概念沙盒（46）此前诊断也是"几何模板滑块空转"重灾区。

**根因**：模型数据用"孤立点+param_t"通用套路建模，未真正表达各自宣称的数学对象；FE-0012 当初只查"字段非空"未查"语义正确"，漏了这一层。

## 2. 验证目标（逐个 82 标的：46 概念沙盒 + 36 跃迁模型）

对每个模型判断并记录：
1. **宣称的数学对象**：从 model_name_zh + camouflage 的 coreSkeleton + kp_dependencies 对应的**真库考点定义**（core.db knowledge_points 的 name_zh + formal_definition）判断"这个模型本该表达什么数学内容"。
2. **实际数据能否表达**：carrier 的 points / canvas_template / 参数滑块 / 遥测，是否真能渲染出该数学对象、交互是否驱动本质变化。
3. **归类**：🔴严重错配(名实不符，如LM-9A-18) / 🟠部分失效(能画但滑块空转/遥测错) / 🟢正确。
4. **坏模型给改造规格**（见第3节格式）。

## 3. 改造规格格式（每个 🔴🟠 模型必须给全）

每个待修模型输出一条规格，字段：
```
{
  "model_id": "LM-9A-18",
  "宣称数学对象": "一元二次方程 y=ax²+bx+c 的判别式Δ决定根的个数 + 韦达定理 x1+x2=-b/a, x1·x2=c/a",
  "现状问题": "carrier只有x1/x2两孤立点被连成线段，无抛物线无系数，param_t空转",
  "canvas_template": "function_quadratic_roots  (← 需前端支持的模板类型，若现有模板不够则命名新类型)",
  "carrier规格": "抛物线 y=ax²+bx+c；随Δ显示与x轴0/1/2交点；标注x1,x2及对称轴x=-b/2a",
  "系数滑块": [{"id":"param_a","name":"二次项系数a","min":-3,"max":3,"default":1,"step":0.1},{"id":"param_b",...},{"id":"param_c",...}],
  "遥测公式": "Δ=b²-4ac（显示值+根的个数判断）; x1+x2=-b/a; x1·x2=c/a（韦达实测）",
  "载体/姿态语义映射": "载体'两交点'=Δ>0 / '切点'=Δ=0; 姿态'开口向上'=a>0 / '开口向下'=a<0",
  "数学验算依据": "例:a=1,b=-1,c=-6 → Δ=25>0, x1=-2,x2=3, x1+x2=1=-b/a ✓, x1·x2=-6=c/a ✓"
}
```
正确(🟢)的模型只需记 {model_id, 结论:正确, 简述}。

## 4. 🔑 关键产出：渲染契约总表（前端 FE-0014 的合同）

**这是本任务最重要的交付物。** 汇总所有规格里用到的 canvas_template 类型，产出一张**"模型类型 × 渲染契约"总表**，供前端渲染引擎升级时据此实现。每类模板定义：
- 模板类型名（如 `function_quadratic_roots` / `function_inverse_proportion` / `locus_trajectory`(瓜豆) / `circle_geometry` / `number_axis_dynamic` ...）
- 该模板需要的输入数据结构（carrier 放什么、需要哪些系数滑块 key）
- 前端渲染引擎该如何消费这些参数画图（如"读 param_a/b/c 画 functiongraph y=ax²+bx+c，按判别式画交点"）
- 遥测该如何按公式实时计算显示
- 覆盖哪些 model_id

目标：前端看这张表就知道"一共要支持哪几类可参数化渲染的数学模型，每类吃什么参数、怎么画、怎么算遥测"。
