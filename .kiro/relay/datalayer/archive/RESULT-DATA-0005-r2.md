## 1. 整改概述与核心诊断
在 attempt 1 验收中，Kiro 确认了：
- ✅ $ 内公式零损坏；
- ✅ 中文不丢字；
- ✅ 题数 2064 不变，备份完整。
但退回指出：
- ❌ **$ 外仍残留 8,010 处 markdown（涉及 205 题）**，集中表现为紧邻中文的单变量（如 `关于*x*的不等式组`、`2*x*≤6`、`[ *x*≥1 ]` 等）未转。

### 根因深度诊断
attempt 1 中在文本清洗末端对**整段文本**执行全局门神校验，而题库原始数据中存在个别历史遗留的不闭合符号（如极少数截断题目的悬空 `$`、历史 `\right.\$`、偶发不对称大括号等）。当整段抛出异常时，退回机制整体 revert 了该题的清洗结果，导致 205 道题直接回退成了原始状态。

### Attempt 2 核心改进措施
1. **多层精准确定性规则增强**：
   - 规则 6~9：处理带撇号变量（`*A*′` → `$A'$`、`*AA*′` → `$AA'$`、`△*A*′*BE*` → `$\triangle A'BE$`）；
   - 规则 7：处理图形下角标（`*S*~△*A*′*DE*~` → `$S_{\triangle A'DE}$`、`*S*~四边形*A*′*BED*~` → `$S_{\text{四边形} A'BED}$`、`*S*~正方形*ABCD*~` → `$S_{\text{正方形} ABCD}$` 等）；
   - 规则 10：几何图形变量（`Rt△*ABC*` → `$\text{Rt}\triangle ABC$`、`△*ABC*` → `$\triangle ABC$`、`∠*A*` → `$\angle A$`、`☉*O*` → `$\odot O$`）；
   - 规则 11：中文加粗标记剥离，中文正文字句 100% 留存；
   - 规则 13~18：多变量/上下标组合（`*a*~n~^2^` → `$a_n^2$`、`*x~E~*` → `$x_E$`、`（*x*﹣1）^2^` → `$(x-1)^2$`、`10^n^` → `$10^n$`、`2^3^` → `$2^3$`、`）^2^` → `）$^2$`）；
   - 规则 19~20：不等式/等式与系数紧邻变量（`2*x*≤6` → `$2x \leq 6$`、`*x*≥1` → `$x \geq 1$`、`*x*＝3` → `$x = 3$`、`3﹣*x*＜5` → `$3 - x < 5$`、`2*x*` → `$2x$`、`﹣*x*` → `$-x$`）；
   - 规则 21：紧邻中文或孤立变量（`关于*x*的` → `关于$x$的`、`则*a*的` → `则$a$的`、`*cm*` → `$\text{cm}$`、`*sin*` → `$\sin$`）。
