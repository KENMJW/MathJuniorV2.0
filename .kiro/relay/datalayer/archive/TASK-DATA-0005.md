# 任务：全库 markdown 残留清洗（pandoc 抽取遗留 → 规范 LaTeX）

## 1. 背景与根因
Kiro 诊断确认:questions.db 大量字段含 **pandoc 从 docx 抽取遗留的 markdown 标记**（非 LaTeX、非 HTML），前端 MathRenderer 不认,原样露出（如 `*a*~0~` `*x*^2^`）导致显示差。**数据本身的数学内容是对的,只是标记格式错。本任务做确定性格式转换,不改数学内容。**

### 残留规模（Kiro 实测）
| 形态 | 数量 | 转换目标 |
|---|---|---|
| `*斜体*`(如 `*A*`/`*x*`) | 61055 | 数学变量 → `$...$` |
| `^上标^`(如 `^2^`) | 2549 | 上标 |
| `~下标~`(如 `~1~`) | 2345 | 下标 |
| 行首 `>` 引用符 | 1061 | 去除 |
| 卷子区块头混入(一、二、本大题…) | 189 | 剔除 |
| 多句号 `。。。/....` | 21 | 收敛 |
- 涉及字段:stem_zh / solutions_json(text) / answer_standard

## 2. 🚨 方法:写确定性转换脚本(不是LLM逐条翻译)
**这是确定性字符替换,必须写一个可测试、可回滚的转换脚本(Python)**,而非让模型逐条"理解着转"(6万处逐条易随机出错且慢)。并发5用于分片跑脚本+抽检验证。

### 转换规则(精确,按顺序)
**铁律:`$...$` 内的内容绝对不动**(已有15469个正确公式片段)。只转 `$...$` 之外的裸 markdown。实现:先按 `$...$` 切段,只对"非公式段"做替换。

组合优先(先长后短,避免拆错):
1. `*x*^2^` `*x*^n^` → `$x^2$` `$x^n$`（斜体变量+上标 组合）
2. `*a*~0~` `*a*~n~` → `$a_0$` `$a_n$`（斜体变量+下标 组合）
3. `*a*~n~x^n^` 这类混合 → 整体转 `$a_n x^n$`（尽量整体成一个$公式$）
4. 独立 `^2^` `^n^`(前面是数字/字母)→ 并入相邻公式或转 `$^2$`
5. 独立 `~1~` `~0~` → 下标并入
6. 剩余单独 `*A*` `*M*` `*x*`(单字母斜体=数学变量)→ `$A$` `$M$` `$x$`
7. 相邻的 `$a$$b$` 尽量合并为 `$ab$`（可选,减少碎片）
8. 行首/独行 `>` 及 `\n>\n>` → 去除(段落用普通换行)
9. 句子中混入的卷子区块头(如末尾 `**二、填空题:(本大题…)**`、`一、选择题`、`本大题N个小题`）→ 剔除该片段
10. `。。。。` `....` → 收敛为单个 `。` 或删除

### 转换后必须校验
- 转出的每个 `$...$` 过**数学门神** `sanitize_and_verify_math()`,不过的**保留原文+记录**(不硬转坏)
- 转换前后**中文正文内容不丢字**(除了该删的区块头/引用符/多句号)
