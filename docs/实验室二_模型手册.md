# 初中数学实验室二：知识谱系演进与高阶模型变式手册

> 本手册是 sandbox.db（步骤4）的**权威直录来源**：12 主线旗舰模型 + 59 种变形形态 + 六学期 36 个模型的四维变式谱系及考点依赖。
> 用途：`leap_sandbox_models`（36 跃迁模型）按此结构化入库；`logic_lines.flagship_model_id` 指向各主线旗舰模型。
> 依据：《中国初中数学知识谱系与学期演进双维归档手册》+《初中数学考点有效组合全集》。

## 二、六学期 36 个数学模型 · 四维变式谱系与考点依赖

> 每个模型：所属学期(解锁) + 考点依赖(kp_dependencies) + 四维变式(载体/参数/姿态/干扰加壳)。
> 四维变式即 leap_sandbox_models 的 carrier_morphing / parameter_morphing / posture_morphing / camouflage_xray。

### 7A 七年级上
- **模型01 数轴动点与绝对值几何距离模型** · 依赖 `KP001+KP002+KP003+KP019`
  - 载体：数轴→折线数轴→平面直角坐标系曼哈顿距离
  - 参数：两定点距离固定→双动点速度相遇追及极值
  - 姿态：单动点折线距离和→含权系数折线和
  - 干扰：物流选址/加油站应用题，X-Ray 还原为中位数取点
- **模型02 线段双中点与角平分线和差模型** · 依赖 `KP044+KP045+KP046+KP019`
  - 载体：单线段→带重叠外部分割；单角→共顶点多重交错角
  - 参数：中点1:1→任意定比m:n
  - 姿态：水平→任意倾斜；角平分线→邻补角内外角平分线垂直
  - 干扰：钟表时针分针夹角，脱壳直击对半公式

### 7B 七年级下
- **模型03 非负数之和为零模型** · 依赖 `KP003+KP006+KP020`
  - 载体：纯代数式→坐标系距离/几何边长平方
  - 参数：双非负→三非负或含参配平
  - 姿态：显式加和→互为相反数 A=-B
  - 干扰：三角形三边代数式求周长
- **模型04 造桥选址平移最短路径模型** · 依赖 `KP045+KP048+KP080`
  - 载体：单河岸→两平行河道/坐标系平行线
  - 参数：河宽常量→随位置动态
  - 姿态：垂直平移→任意角度造桥
  - 干扰：城市管道铺设，X-Ray 扣除平移量拉直
- **模型05 二元一次方程组与坐标系交点模型** · 依赖 `KP020+KP029+KP031`
  - 载体：纯代数消元→动直线相交轨迹
  - 参数：常系数→含参k直线族象限分布
  - 姿态：斜交→平行(无解)/重合(无穷)/垂直
  - 干扰：线性规划可行域面积

> 每个模型四维变式含义统一：
> - **carrier_morphing 载体变异**：模型迁入特殊四边形/圆/坐标系/抛物线等载体
> - **parameter_morphing 参数变异**：常数/特殊角 → 连续变量/含参代数式/闭区间
> - **posture_morphing 姿态变异**：标准态 → 倾斜/倒挂/反转/辅助线隐去
> - **camouflage_xray 干扰加壳**：包裹进压轴多问 + X-Ray 骨架透视剥离外围

## 三、旗舰模型 flagship_model_id 映射（logic_lines）

每主线的旗舰模型 = 该主线全要素闭环模型（对应第一节 12 模型）。model_id 命名 `LM-<学期><序号>`，如 `LM-9A-19`（手拉手）。旗舰模型指定见入库时按主线选其代表模型。

---

## 四、注意：考点 ID 映射
本手册用旧 ID `KP001` 记法；入库时须转为 core.db 的连字符格式 `KP-001`（与 §11.2 一致）。kp_dependencies 存 core.db 白名单校验后的 KP-0xx 数组。
