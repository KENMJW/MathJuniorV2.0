## 四、⚡ 当前最需要讨论：Q4 连接强度方案

这个决策直接影响 **Step 2（LLM关联分析）** 和 **Step 3（组合枚举）** 的实现。

### 方案对比

| | 方案A：二值 | 方案B：三级权重 | 方案C：二值+评分 |
|--|------------|--------------|----------------|
| **连接输出** | 有 / 无 | 强(3)/中(2)/弱(1) | 有/无 + 组合整体评分 |
| **Clique算法** | 标准BK算法 | 带阈值BK算法 | 标准BK + 后处理评分 |
| **LLM调用** | 一次判断 | 一次判断（更多输出） | 两步（先判断再评分） |
| **组合质量控制** | ❌ 无法区分 | ✅ 可按权重过滤 | ✅ 可按分数过滤 |
| **实现复杂度** | 低 | 中 | 中 |
| **LLM一致性** | 高（二值稳定） | 中（三级有歧义） | 高+高 |

### 我的建议：**方案C（二值+评分）**

```
原因：
1. LLM 判断"有/无连接"最稳定，不容易出错
2. 组合整体评分用规则计算（不依赖LLM），结果可复现
3. 下游可以自由设置过滤阈值

评分规则（示例）：
  组合评分 = 组合内所有边的 min(强度) 
           × (1 + 跨领域bonus × 0.2)
  
  边强度来源：LLM判断 有/无 后，
  再由规则推断：同小类=强，同领域跨类=中，跨领域=弱
```

## 五、新增需要澄清的问题

> [!IMPORTANT]
> 确认学段扩展到小学/高中后，有几个新问题需要确认：

### 🔴 新问题

**NQ1：学科范围具体是哪些？**

| 学段 | 候选学科 |
|-----|---------|
| 小学 | 数学、科学（综合理科） |
| 初中 | 数学、物理、化学、生物、地理 |
| 高中 | 数学、物理、化学、生物、地理 |

- 选项A：**只做数学**（三个学段）
- 选项B：**理综四科**（数/物/化/生，三学段）
- 选项C：**全部理科**（含地理，三学段）

**NQ2：跨学科组合是否需要？**

例如：初中物理的"速度" ＋ 初中数学的"一次函数" — 这是一个非常常见的实际考题组合。

- 选项A：**只做单学科内部**（每科独立运行）
- 选项B：**支持跨学科组合**（不同学科的考点可以组合）

**NQ3：小学"理科"如何处理？**

小学阶段通常没有分科，只有：
- 数学（1-6年级）
- 科学（综合，3-6年级）

这两科的知识点关联性与初中不同，**是否需要单独处理小学的连接逻辑**？

## 六、Step 4 有向验证——实现方案

> 这是新增的核心逻辑，需要明确。

```
目的：
  给定无向组合 {A, B, C}，
  检验是否存在一种有向排列（如 A→B→C）
  使得这个排列"能出题"

判断标准（待讨论）：
  ① 宽松标准：存在任意一种合法排列即可
  ② 严格标准：所有考点必须对学生同时可知（无前置障碍）

LLM判断 prompt 示例：
  "以下考点组合: [有理数运算, 因式分解, 一元二次方程]
   是否存在一种题目，使学生需要同时运用这三个知识点？
   如果是，给出一个出题思路（30字以内）。"

输出：
  {
    "combination_id": "C3-0042",
    "is_question_valid": true,
    "valid_order": ["KP001", "KP014", "KP021"],
    "question_hint": "已知整式展开后求方程的根"
  }
```
