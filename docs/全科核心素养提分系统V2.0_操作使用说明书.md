# 第一章：系统简介与三端体验指南

传统理科学习常常陷入“死记公式、机械刷题、一遇到图形变形就束手无策”的困境。**全科核心素养提分系统 V2.0** 将初中数学从干瘪的教科书文字，升级为**“看得见、摸得着、能变形”**的动态实验世界。

## 1.1 手机、平板、电脑三端使用差异速查表

系统支持在任意手机浏览器、iPad 平板或电脑上无缝使用，界面会自动感知屏幕尺寸并自适应匹配最佳排版：

| 设备形态 | 最佳使用姿势 | 界面交互特色 | 学生 / 家长操作建议 |
| :--- | :--- | :--- | :--- |
| **电脑端 (PC / Mac)** | 宽屏桌面浏览，鼠标 + 键盘微调 | 左侧精讲卡片 + 右侧深色几何视口并排展示，滑块支持键盘精准微调 | 适合晚间系统复习、完整模拟考与中考真题大卷作答 |
| **平板端 (iPad / 平板)** | **横屏推荐**（配合支架使用） | 支持双指捏合缩放视口、指尖平滑拖拽动点，侧边浮动抽屉按需滑出 | 极其推荐课后巩固与错题探究，兼具大视野与指尖触感 |
| **手机端 (iPhone / 安卓)** | 竖屏单手操作 / 双手横屏 | 顶部学期胶囊快速定位、底部抽屉纵向上滑展开、核心测度条智能贴底 | 适合碎片时间进行“概念四段论”速读与极速自测闯关 |

> [!TIP]
> **三端防迷失小窍门**：拖动几何图形跑出视野时，电脑端在空白区域**双击鼠标左键**即可自动居中复位；手机/平板端轻触画布角落的**小标尺复位图标**，毫秒级恢复黄金视野。

## 1.2 顶栏全局控制台：学期与双语随心切换

无论处于哪个模块，屏幕顶栏常驻核心控制条：
1. **学期定位（7上 ~ 9下）**：点击顶部学期胶囊（如 `8下`），系统立即过滤出初二下学期的勾股定理、平行四边形、二次根式等专属考点。
2. **中英双语一键切换（中 / EN）**：考点名称、名师题眼、沙盒滑块、几何定理全量支持中英对照，助力双语教学与国际课程素养拓展。
3. **零持久化隐私保护**：系统不记录学员私人敏感信息，草稿随用随清，页面刷新即刻恢复标准黄金初态，保护作答安全。

# 第三章：探本溯源 · 考点精讲与具象沙盒

每个考点配备**四段论精讲**与**深色动力沙盒**，让学生把抽象定理亲手做出来。

## 3.1 考点四段论学习法
- **① 原初故事**：古代数学家在什么生活难题中发现了该定理？
- **② 直觉本质**：用通俗大白话讲透原理；
- **③ 形式定义**：教科书规范公式与推导；
- **④ 内在变异**：中考命题人最喜欢从什么角度变形设卡。

## 3.2 具象沙盒实操：动点拖拽、探究三步曲与实时 HUD
- **动点拖拽**：黄色/橙色圆点均为动点，可手指或鼠标拉动；
- **实时 HUD 守恒验证**：数值毫秒级计算，满足守恒时打上绿色对勾 `[恒等守恒成立 ✓]`；
- **达成条件**：完成要求后步骤卡片点亮。

## 3.3 实操范例：探究“勾股定理赵爽弦图与三方外挂 (SB-KP057)”

1. 在考点列表中选择 **“KP-057：勾股定理”**，右侧加载 Slate 950 深色画布；
2. **步骤 1：直角边独立变形**。拉动直角边滑块 $a=3, b=4$，实时 HUD 瞬时呈现：
   $$a^2 + b^2 = 25.00 \equiv c^2 = 25.00$$
3. **步骤 2：切换赵爽弦图模式**。调节 `view_mode = 2`，画布呈现 4 个直角三角形围绕中心小正方形的古代赵爽弦图，面积守恒一目了然：
   $$c^2 = 4 \times \left(\frac{1}{2}ab\right) + (b-a)^2 = a^2 + b^2$$
4. **达成目标**：步骤卡片点亮为绿色完成态。

# 第四章：见微知著 · 4D 跃迁变异实验室

中考最后两道几何与代数压轴题，往往由基本模型经“旋转、加壳、掩护”而成。4D 实验室收录中考 37 个旗舰跃迁模型。

## 4.1 模式一：名师分步推演（Step Deduction）流程
- **① 原初骨架**：剥离干扰，呈现纯净基础模型；
- **② 动态变异**：图形旋转变异，临界态出现；
- **③ 出题人伪装**：添加考卷中常见的辅助阴影与假线索；
- **④ [透视] 照妖镜开启**：X-Ray 开启，干扰线透明化，骨架发光呈现，并揭秘**中考题眼**。

## 4.2 模式二：4D 变异自由探索（Free Explore）实操技法
- **① 载体变异 (Carrier)**：等边三角形 / 等腰直角 / 正方形 / 坐标系自由切换；
- **② 参数变异 (Parameter)**：通过滑块调节旋转角、比例、线段长度；
- **③ 姿态变异 (Posture)**：支持 $90^\circ$ 旋转、空间正交投影与轴对称翻折；
- **④ 干扰加壳与透视 (Camouflage & X-Ray)**：随时开启照妖镜剥离伪装。

## 4.3 实操范例：攻坚中考几何王牌“手拉手旋转全等模型 (LM-9A-19)”

1. 在 4D 模型库中点选 **“LM-9A-19：手拉手模型”**；
2. **步骤 1**：旋转角 $\theta=60^\circ$，实时遥测确认 $\triangle OAC \cong \triangle OBD$，$AC = BD$ 严格相等；
3. **步骤 2**：姿态变异至 $90^\circ$，旋转线段夹角恒等于 $90^\circ$，两旋转线段互相垂直；
4. **步骤 4**：开启照妖镜，外围加壳线淡化，核心旋转三角形浮现，题眼总结：“旋转恒全等且两线夹角恒等于旋转角 $\alpha$”。

# 第七章：家长辅导指南与常见操作答疑 (FAQ)

## 7.1 家长陪伴锦囊：四步提问法引导孩子独立思考
1. **第一步（观察不变量）**：“宝贝，拖动这个黄色圆点，看看下面哪两个数据一直没变？”
2. **第二步（探寻数学规律）**：“为什么图形旋转了角度，面积还是完全一样？底和高有什么关系？”
3. **第三步（识破出题人加壳）**：“点一下照妖镜，看看出题人加的三条虚线，是不是为了把手拉手全等藏起来？”
4. **第四步（独立达成通关）**：“把探究目标达成，等看到绿色 `[守恒成立 ✓]` 就算真正攻克难关！”

## 7.2 常见操作答疑 (FAQ)

- **Q1：为什么每次刷新网页后，调节的滑块会恢复默认值？**  
  **A**：系统采用严格的“零持久化安全机制”。刷新即恢复标准初态，保护隐私并方便学生每次都从清晰的黄金基准开始推演。

- **Q2：图形拖动太大或移到屏幕外面了怎么办？**  
  **A**：电脑端在空白区域**双击鼠标左键**，平板或手机端轻触角落的**复位小标尺**，画布自动居中归位。

- **Q3：离线没网络能用吗？**  
  **A**：**完全可以**。系统基于浏览器本地 SQLite WASM 技术构建，首次打开后数据已安全缓存，离网断网均可畅爽探究。

- **Q4：英文模式有什么用？**  
  **A**：点击顶栏 [EN] 可切换双语，培养双语学术素养，对接高中竞赛与国际理科课程。
